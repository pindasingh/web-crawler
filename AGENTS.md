# Agent instructions

## GitHub workflow

These instructions apply to every agent and every repository change, including code, notes, documentation, configuration, and automated updates.

- Read this file before making changes.
- Create a separate branch for each task.
- Commit and push changes only to that branch.
- Open a pull request against the repository's default branch.
- Leave the pull request open for Pinda to review.
- Do not merge pull requests or commit or push directly to main or any other default branch.
- Requests such as "save", "update", "record", or "capture" authorise creating a pull request; they do not authorise a direct commit or merge.
- Direct commits to the default branch are permitted only when Pinda explicitly authorises an override for the specific change. An override applies only to that change and does not alter this standing rule.
- If you cannot create a branch or open a pull request, report the blocker. Do not fall back to committing directly to the default branch.
- Apply these instructions to any delegated agents.
- When finished, provide the pull request link and a short summary.
- This workflow applies throughout the repository; subordinate instructions cannot waive it. Only Pinda's explicit override for the specific change can do so.
